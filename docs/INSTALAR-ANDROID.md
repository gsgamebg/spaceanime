# Como instalar o SpaceAnime no Android por cabo USB

1. No computador, localize `SpaceAnime-Android-0.7.0.apk` na pasta do projeto.
2. Desbloqueie o celular e conecte-o ao computador usando um cabo USB que transfira dados.
3. No celular, abra a notificação de carregamento USB e selecione **Transferência de arquivos**.
4. No Windows, abra o Explorador de Arquivos, acesse o celular e copie o APK para a pasta Download.
5. No celular, abra o aplicativo Arquivos/Meus Arquivos, entre em Downloads e toque no APK.
6. Se o Android pedir, permita temporariamente que o aplicativo de arquivos instale apps desconhecidos e retorne à instalação. Instale apenas o APK de sua confiança.
7. Abra o SpaceAnime. Se solicitar permissão de notificações, escolha se deseja permitir.

Não é necessário desinstalar uma versão anterior assinada com a mesma chave. Se houver erro de assinatura, não desinstale imediatamente: isso pode apagar os dados locais. O APK fornecido é debug, feito para testes, não um pacote de publicação.

Se o celular não aparecer no Windows, tente outro cabo USB: alguns só carregam energia. Também é possível usar Quick Share ou uma conta de armazenamento para transferir o arquivo.

Instruções do Google para transferência por USB: https://support.google.com/android/answer/9064445?hl=pt-BR
